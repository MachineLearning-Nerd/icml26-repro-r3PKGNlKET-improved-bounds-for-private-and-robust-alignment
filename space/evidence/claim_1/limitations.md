# Claim 1 limitations and deviations

There is no Monte Carlo experiment: the paper's statement is universally
quantified, so the primary evidence is a machine-checked symbolic derivation.
The executable checker exhausts a rational grid only as an independent
implementation check, not as proof. Constants are explicit in the reconstructed
argument but the paper states only a universal-constant order bound.

The historical assertion that a fitted slope was `-1` is rejected and is not
used.
